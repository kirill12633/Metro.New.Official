Конвертация идёт прямо в браузере. Изображения не отправляются на сервер и нигде не сохраняются.

Как конвертировать изображения онлайн

  1. Перетащите картинки в рамку, нажмите на неё или вставьте изображение из буфера обмена.
  2. Выберите формат: JPG, PNG или WebP. При необходимости настройте качество и максимальную ширину.
  3. Результат появится сразу. Скачайте файлы по одному или всё вместе одним ZIP-архивом.

Пока вы меняете настройки, все файлы в списке пересчитываются автоматически. Регистрация не нужна, ограничений по числу конвертаций нет.

Какой формат выбрать

  • JPG. Лучший выбор для фотографий и максимальной совместимости: открывается везде. Не поддерживает прозрачность.
  • PNG. Подходит для скриншотов, логотипов и графики с прозрачным фоном. Сжимает без потерь, поэтому файлы тяжелее.
  • WebP. Обычно даёт файл заметно меньше JPG при том же внешнем качестве и умеет прозрачность. Хорош для сайтов, но в старых программах может не открываться.

Как уменьшить размер картинки

Для JPG и WebP начните с качества 80-85: на глаз разница с оригиналом почти незаметна, а файл становится заметно легче. Дополнительно можно ограничить ширину. Для сайта обычно хватает 1600-2000 пикселей, для соцсетей и мессенджеров ещё меньше. Размер никогда не увеличивается: если картинка уже уже заданной ширины, она остаётся как есть.

Прозрачность и фон

PNG и WebP хранят прозрачные области. В JPG прозрачности нет, поэтому такие области заливаются выбранным цветом фона, по умолчанию белым. Если логотип светлый, выберите тёмный фон, иначе он потеряется.

Приватность и метаданные

Файлы обрабатываются только на вашем устройстве. При пересохранении данные EXIF (геолокация, модель камеры, время съёмки) в новый файл не попадают, а поворот фото сохраняется. Это удобно, если перед публикацией нужно убрать из снимка лишнюю информацию.
