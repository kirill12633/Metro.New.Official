Как пользоваться калькулятором?

1. Premium-выплаты: Введите количество визитов (посещений игры) за месяц и среднее время в минутах (данные можно взять с Rolimons). Калькулятор покажет, сколько вы заработаете за месяц.

2. Game Pass: Укажите количество оценок (рейтинг) под пассом и его цену в Robux. Система рассчитает примерный доход от продаж.

3. USD: Доход в долларах считается по курсу 1 Robux = 0.0035 USD с вычетом комиссии 5 USD за вывод.

Формулы для самостоятельного расчёта

📌 Premium выплаты (в Robux):
X × 0.05 × Y × 0.001
X — визиты, Y — среднее время (мин)
📌 Game Pass (в Robux):
X × 50 × Y × 0.7
X — оценки, Y — цена пасса
📌 Перевод в USD:
( Robux × 0.0035 ) − 5
5 USD — комиссия за вывод через DevEx

API — Встраиваемый калькулятор

Вы можете встроить этот калькулятор на свой сайт или использовать API для получения данных.

📡 Доступные API Endpoints:

GET
/api/earnings/premium
Рассчитать Premium выплаты
Параметры: ?visits=100000&time=20
GET
/api/earnings/gamepass
Рассчитать доход от Game Pass
Параметры: ?ratings=200&price=100
GET
/api/earnings/players
Сколько нужно игроков
Параметры: ?target=10000&time=20
GET
/api/earnings/compare
Сравнить Premium vs Game Pass
Параметры: ?visits=100000&time=20&ratings=200&price=100
// Пример использования API

// 1. Premium выплаты
fetch('https://kirill12633.github.io/Metro.New.Official/api/earnings/premium?visits=100000&time=20')
.then(res => res.json())
.then(data => console.log(data))

// Ответ:
{
"robux": 100,
"usd": 0.35
}

// 2. Game Pass
fetch('https://kirill12633.github.io/Metro.New.Official/api/earnings/gamepass?ratings=200&price=100')
.then(res => res.json())
.then(data => console.log(data))

// 3. Сколько нужно игроков
fetch('https://kirill12633.github.io/Metro.New.Official/api/earnings/players?target=10000&time=20')
.then(res => res.json())
.then(data => console.log(data))

// 4. Сравнение
fetch('https://kirill12633.github.io/Metro.New.Official/api/earnings/compare?visits=100000&time=20&ratings=200&price=100')
.then(res => res.json())
.then(data => console.log(data))

📦 Как встроить калькулятор на свой сайт:

<!-- Вставьте этот блок в любое место на вашем сайте -->
<div id="roblox-calculator"></div>
<script src="https://kirill12633.github.io/Metro.New.Official/ru/tools/roblox-calculator/embed.js"></script>

После загрузки скрипта калькулятор автоматически появится в блоке с id="roblox-calculator"
